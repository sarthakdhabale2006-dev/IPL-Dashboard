IPL Analytics & Predictor Dashboard

This is a premium, client-side, single-page application built as a data science portfolio project. The dashboard aggregates over 17 years of historical Indian Premier League (IPL) matches and ball-by-ball delivery datasets, providing comprehensive statistics, rosters landmarks, yearly records, and win-probability calculation engines.

Key Features

Visual Dashboards

Chart.js visualizations plotting team wins, seasonal matches, runs progression, toss choices, and venues distribution.

Deep Filters

Slice and dice match statistics across seasons, venues, and franchises instantly with cached browser indexes.

Rosters & Players Profile

Autocomplete player searches evaluating career aggregates, boundary count, strike rates, economy, and best bowling.

Multi-Factor Predictor

Predict match outcomes using a statistical formula weighting Head-to-Head (35%), Venue (20%), Form (20%), Toss (15%), and Overall strength (10%).

Technical Stack

  • Core: HTML5, Vanilla CSS3 (Custom Variables, Flexbox, Grids, Transitions, Keyframes).
  • Layout System: Custom Glassmorphism cards with CSS backdrop filter blurs and premium dark styling.
  • Data Parsing: In-browser CSV tokenizer using PapaParse for lightning-fast deliveries index compile.
  • Charts Engine: Chart.js rendering bar, pie, line, doughnut and horizontal axes.
  • Vector graphics: Font Awesome vectors and SVG arcs for the winning probability gauge.

Keyboard Shortcuts & Utilities

- Alt + T: Toggle Light / Dark mode themes instantly.
- Alt + F: Toggle Fullscreen window mode.
- PDF Export: Clicking "Export PDF" in the header will optimize the view and open the system print dialog. Save as PDF.
